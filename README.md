# VoBi

**VoBi** soll nachgeriechte Zeit einträge erleichtern, dadurch muss man nicht jedes mal nachdenken,
wenn man Zeit nachträgt :)  

![Version](https://img.shields.io/badge/version-0.1.0-8A2BE2) ![Made with Rust](https://img.shields.io/badge/Made%20with-Rust-orange?logo=rust)

```
Sagt dir, von wann bis wann du gearbeitet hast

Usage: vobi [OPTIONS] <START>

Arguments:
  <START>  Startzeitpunkt 0730 (7.30 Uhr)

Options:
  -b, --bis <ENDE>  Endzeitzeitpunkt 1800 (18:00 Uhr)
  -h, --help        Print help
  -V, --version     Print version
```
